# HERO Logistics SaaS — Super Admin Flow & Implementation Document

## Overview
Defines the boundary and responsibilities of the Super Admin (Platform Owner) portal.

## Core Responsibilities
1. **Platform User Management:** Create and manage all HERO platform users, including staff with Role = `SALES` (`SALES_FULL_ACCESS` and `SALES_REP`).
2. **Tenant Provisioning:** Review onboarding handovers from Sales, provision new Company workspaces, configure SaaS subscription tiers, and govern trial expirations.
3. **SaaS Billing & Platform Revenue:** Track actual platform subscription charges, payments, and invoices (separate from individual carrier freight invoices).
4. **Feature & Module Access:** Control licensing tiers (Core, Premium, Enterprise Add-ons).
5. **System Governance:** White-label customization, support ticket resolution, global audit logs.
